MovieMinded 🎬
MovieMinded is a full-stack movie streaming platform inspired by Netflix. Users can explore movies, check top trending titles, read reviews, and search for any movie. Admins can manage the platform by adding new movies through a dedicated dashboard. The project is built with React.js, Node.js, and MongoDB, featuring a modern, responsive UI with a dark/red theme.

🔹 Features
For Users:
Browse trending movies.
Search for movies with detailed information (title, year, genre, description, etc.).
View streaming partners and user reviews.
Responsive and modern interface for all devices.

For Admins:
Login securely to the admin panel.
View all added movies in a dashboard.
Add new movies with images, videos, and details.
Fully responsive admin interface.

Installation & Setup

Clone the repository:
git clone https://github.com/zohaibJR/MovieMinded


Install backend dependencies:
cd .\movie-backend\
npm install


Install frontend dependencies:

cd .\moviebase\ 
npm install


Set up .env file for backend (MongoDB URI, JWT secret, etc.).

Start the backend server:

cd .\movie-backend\
npm start


Start the frontend:

cd .\moviebase\ 
npm start
